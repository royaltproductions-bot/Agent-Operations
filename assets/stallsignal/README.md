# StallSignal — Is that vendor booth worth it?

A free, tiny, offline-first browser calculator for people considering a craft fair, pop-up shop, market booth, or local vendor event.

**Use it:** Download [index.html](./index.html) and open the file in any modern browser. No installation, server, account, internet connection, ads, cookies, tracking, or data upload. All calculations run locally. Saved comparisons use only your browser's localStorage; you can export them as CSV.

## The one job it does

Before paying a booth fee, estimate how many customers you would need to break even. Enter event attendance, expected booth visits, conversion rate, average order size, cost of goods, card fees, organizer commission, travel, supplies, and hours. The calculator shows:

- Break-even order count and approximate traffic required.
- Expected cash profit and effective hourly earnings.
- Conservative, base, and optimistic scenarios.
- Save/compare multiple events and export results as CSV.

**Why:** An event with a big crowd can still be a money-loser when booth costs and low conversion are included. This gives a quick reality check before committing money.

## Scope and limitations

This is a **scenario planner**, not a prediction, tax calculation, bookkeeping system, or guarantee of sales. Attendance, conversion, and basket size are user assumptions. Review sales tax, refunds, inventory cash timing, weather, and contractual terms separately. No vendor payments or external transactions are initiated.
